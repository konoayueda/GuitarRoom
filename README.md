# 弦间 · 个人吉他练习室

以曲谱为中心的个人吉他工具网站。目前已实现曲谱收藏与阅读、练习笔记、和弦探索，以及第二期的可视化编排、六线谱片段识别与分段试听，适配桌面与手机。

## 已实现

- 曲谱库：上传 JPG、PNG、WebP 或 PDF，整理曲名、作者、调性、变调夹和标签；收藏、搜索、排序与练习状态。曲谱卡片和阅读器均可删除曲谱，确认后同时移除原文件、笔记和编排；删除示范谱后刷新也不会重新出现。
- 阅读器：顶部页面缩略图、直接跳页、多页浏览、记住上次页码、调整页序、旋转、缩放、专注模式和自动滚动。图片与 PDF 按实际显示宽度和屏幕像素密度重新绘制；PDF 缩放与翻页复用已下载文档。
- 演奏阅读：从原谱进入独立全屏布局，按保存页序连续阅读图片和多页 PDF；选起始页（可跳过封面）、3/5 秒或无倒计时、可调速自动滚谱、空格暂停/继续、方向键及 PageUp/PageDown 移谱。拖动、切后台或调整窗口时暂停，谱尾停止；支持浏览器全屏和屏幕常亮（不支持时提示）。本设备记住速度、缩放与页内位置；原谱批注和识别继续在普通阅读器操作。共享 PDF 下载，稳定页面高度，仅渲染邻近页面，避免长谱堆积高清画布。
- 笔记：谱面圈选 / 点按批注、练习笔记；旋转时批注位置随页面变换。保存失败保留当前草稿。
- 和弦实验室：常用和弦与指型、交互指板、按弦位置反查和弦、变调夹换算、组成音与和弦试听、具体指型收藏。
- 换指练习：手动选择前后和弦，提示相同指位可保留的手指；将选定和弦加入临时进行，按设定速度循环试听。
- 节拍器：30–240 BPM，3/4、4/4、6/4；手机收起练习面板后仍继续运行。
- 备份：ZIP 包含原始曲谱，以及记录页序、旋转、标签、批注和笔记的 JSON。原文件可重新导入；暂未实现从 JSON 一键恢复整套整理信息。
- 三份原创示范六线谱，不使用第三方曲谱内容。
- 编排与试听：原谱对照、段落和小节增删/复制/排序、具体和弦指型、十六分 / 三十二分、附点 / 复附点和三连音时值、休止、拍号、速度、段落播放遍数、整曲/选段循环、小节与事件高亮。提供和弦扫奏及八分分解音型，遵循当前曲谱的 Capo。
- 可视化编排：整张六线谱就是编辑区。点和弦可就地切换按法、拆分时值或清为空拍；切换八分、十六分、附点或三连音网格，点某弦的拍点直接输入 0–24 品；输入 X 或点「× 按和弦拨弦」跟随当前和弦的相应弦品位，方向键移动，Delete / Backspace 清除单音。手机使用当前格点下方的数字输入框。谱面上可直接插入、复制、移动和删除小节，修改段落名与播放遍数；支持撤销、重做、同步试听及原谱页关联。每个单音可独立设置时值；同弦同品的相邻音可用「连到下一同音」连接，支持跨事件及连到下一小节开头，合并后只拨弦一次。切换网格仍保留并显示已有音符。
- 谱面与播放器共用拨弦数据，品位相对变调夹。缩短时值自动留下休止，延长只占用后续空拍；手动音符随拆分分配，复制互不影响。默认扫弦 / 分解变化保留手改音符；更换和弦保留手工音符与节奏，仅更新 × 的实际品位，明确数字不变。点击「恢复和弦音型」才重新生成该事件。可选同时拨弦、向下或向上扫弦；常见按法不合原谱时，可展开「核对原谱和弦按法」，逐弦填写品位。
- 节奏谱面：音符下方显示符头、符干、单 / 双 / 三符杠、附点 / 复附点、休止及三连音括号。完整三连音显示「3」，不完整组显示「3:2」；6/8 按三枚八分音符分组，同拍不同时值分层显示。扫弦箭头遵循谱面弦位方向，延音保留连线。
- 编排阅读：原谱阅读、编排阅读、编排编辑分为三个独立视图。编排阅读将所有段落和小节连成完整谱面，支持缩放、整曲试听、循环与自动滚动；编辑页可一键进入阅读，已保存编排在重新打开曲谱后仍可阅读。未保存预览会单独标明。
- 编排保存与草稿：保存在曲谱 JSON 中，完整备份包含编排；还可单独导出编排 JSON。未保存修改在当前页面的琴房中暂存，切换曲谱或和弦实验室可继续编辑；离开或刷新浏览器会提醒保存。旧保存响应不会清除后来的修改。

- 六线谱片段识别：在原谱阅读中点击「框选识别」，或从编排工具栏进入，拖出一行完整小节。浏览器本地检测弦线、小节线、品位和部分常见和弦标记；图片读取原文件，PDF 独立高清渲染选区，不包含批注。首次识别需加载随站点提供的 OCR 资源，曲谱图像不发送给外部识别服务。
- 识别校正：逐小节对照高清原图片段与草稿，修改品位、弦位、拍点及和弦，移除误识别或补入漏音。× 按当前拍点的和弦指型解析，数字保留指定品位；支持自定按法及小节内多次换和弦，追加时按换和弦拍点分成事件。识别出的多个和弦会保留为待核对的换和弦位置。确认每小节的音符和节奏后，追加为一个可编辑段落；保留现有编排并可一次撤销。关闭校对或在琴房内切换页面会保留当前识别草稿，重新框选失败不会丢弃旧草稿；刷新页面前需完成加入和保存。

## 阶段边界

当前试听来自手动编排或识别后校正的和弦与音符，使用浏览器合成拨弦音色。可视化编辑作用于编排中的六线谱，不修改上传的原文件。

本地识别目前适合清晰、水平、印刷的六线谱，一次一行，建议 1–4 个完整小节，最多 8 小节。纯歌词和弦谱、手写谱、斜拍、复杂装饰符号及自动整页识别尚未支持。当前采用中文弹唱六线谱的读法：「×」表示按相应和弦拨对应弦，数字指定该弦的实际品位（可以覆盖和弦按法）。未设置和弦或对应弦不可弹时，必须补全按法才能确认 / 保存，不会猜成空弦；尚不能可靠处理整页混合简谱、歌词、和弦图和复杂节奏的弹唱谱，也不支持闷音试听。不同字体仍可能误读或漏读，必须逐小节核对，不能将识别置信度当作准确性保证。拍点按音符列均匀排布作为草稿，尚未自动读懂节奏；弦位、品位、和弦与拍点均可人工修正。当前编排已有段落时，新识别片段的拍号必须一致。后续再扩展更完整的节奏识别、弹唱谱识别、演奏示范与同步落指引导。

编排 v2 以四分音符为 24 tick：4/4 每小节 96 tick，3/4 与 6/8 每小节 72 tick；速度仍以四分音符每分钟计。支持十六分 / 三十二分、附点二分 / 四分 / 八分 / 十六分、复附点二分 / 四分 / 八分，以及四分 / 八分 / 十六分 / 三十二分三连音。事件占满小节，音符起音和独立时值分别保存；延音只连接时间相邻的同弦同品音符。单音时值不能覆盖后续同弦音或直接越过小节，跨小节用延音连接。改变网格不移动已有音符；缩短事件不能丢弃后面的音符，插入后音会截短同弦前音，删改音符会清理失效的延音。最多 16 段、128 小节，每段 1–8 遍，每事件最多 144 个手动音符。

旧 v1 编排在读取时按 12 倍换算时值和起音位置，保持原速度、分解密度及原有试听，写入版本校验仍使用原始记录，无需数据库迁移。旧版本备份提交到 API 也会升级为 v2。识别草稿仍按八分网格排布，加入编排时换算为新时间单位；复杂节奏需要在编排页人工校正，尚未增加自动节奏识别。选段保留段落遍数；延音不会误连到反复或循环跳转后的音，从续音所在小节单独开始试听时会正常拨响。

## 记谱参考

- [吉他社：吉他谱六线谱入门](https://www.jitashe.org/school/tablature/)：弹唱谱的 × 根据上方和弦按弦，数字明确指定品位。当前产品使用这一约定；Guitar Pro 中 × 作为 dead note 的约定不同，目前没有导入 Guitar Pro 文件或闷音试听。
- [Guitar Pro：连音](https://www.guitar-pro.com/docs/gp8/score/note/tuplet)与[时值符号](https://www.guitar-pro.com/docs/gp8/score/note/symbols/note)：三连音按正常两枚音符的时间演奏三枚，附点增加原时值的一半，复附点再增加四分之一。
- [MuseScore：符杠](https://handbook.musescore.org/notation/rhythm-meter-and-measures/beams)：用符杠组织节拍内的短时值音符。当前实现固定拍号的常见分组，尚不支持用户自定符杠或任意连音比。

## 本地运行

需要 Node.js 22.13 或更高版本。此项目使用 React、TypeScript、vinext / Vite、Cloudflare D1 与 R2、PDF.js 和 Web Audio。

```sh
npm ci
npm run dev
```

默认预览地址为 http://localhost:5173/ 。当前为免登录的本机琴房：直接打开本地开发服务即可导入曲谱、保存笔记与编排、收藏和弦，不依赖登录 Cookie。沿用原来的本地存储空间，已有曲谱无需迁移或重新导入。免登录数据访问仅在开发模式且请求主机为 localhost / 127.0.0.1 / ::1 时开放；生产构建与其他主机拒绝数据访问，防止现有曲谱被意外公开。开发数据保存在 `.wrangler/state`，不随源代码发布。

新检出的目录还需要初始化本地数据库（只执行一次；现有工作区已经执行）：

```sh
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_left_gwen_stacy.sql
```

`.openai/hosting.json` 声明 DB 和 BUCKET 绑定。数据库保存曲谱信息、笔记和指型，R2 保存原始文件；API 校验本机使用范围、请求来源、文件签名和写入版本。多标签页使用旧版本保存时返回冲突，防止静默覆盖。曲谱删除先写入只保留标识的删除记录并关闭文件访问，再清理存储；清理中断会在下次读取曲谱库时重试，无需数据库迁移。迟到的列表响应不会恢复已删除项或覆盖刚完成的保存。

单次导入可选最多 20 张图片，或 1 份最多 200 页的 PDF。每个文件不超过 20 MB，单次总量不超过 40 MB。第一期使用标准调弦 E A D G B E。

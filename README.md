# 弦间 · 个人吉他练习室

以曲谱为中心的本地个人吉他工具。目前已实现曲谱收藏与阅读、练习笔记、和弦探索，以及第二期的可视化编排、六线谱片段识别与分段试听，适配桌面与手机。

## 已实现

- 新建自定义和弦：和弦选择窗口中可从零新建，自行填写名称及 6 弦到 1 弦的品位，按法图实时预览；留空表示不弹，0 是空弦，支持 1–24 品。校验名称、品位与至少一根可弹弦，中文输入确认不会误提交。加入前的局部输入与返回、取消不修改编排；添加被拒绝时保留填写内容。自定义和弦随编排保存，并在当前这份谱子的选择窗口中可搜索复用，包含在备份中并用于试听；保留原有手写音符，支持中途换和弦、撤销重做与阅读。
- 直接添加和弦：点击谱面「和弦 +」、属性面板「全部和弦」或谱面右键「添加和弦」，直接打开可搜索的选择器，无需先填写 C 等初始按钮中的和弦。展示现有 26 种常用按法及六弦到一弦的品位，同名不同按法可分别选择，支持升降号、等音拼写和键盘选择。从事件内部添加时保留前段音乐，从所点拍位切换，后续音乐时间、手写数字音符、歌词和唱音位置保持；可整次撤销、保存后阅读。
- 自动谱首：编排编辑与独立阅读自动显示起始括线、竖排 TAB、上下排列的拍号和唱音调号（如 1=G），悬停可查看含义。新编排按曲谱调性初始化唱音调，小调使用对应的相对大调；已保存编排保留原有唱音调。谱首的拍号与调号跟随设置更新，可直接右键修改。
- 谱面右键菜单：右键点击音符、和弦、唱音或歌词即可选择对应目标，调整时值、附点、三连音、延音、音高或歌词行，清除内容、复制剪切粘贴、增删复制小节以及撤销重做。歌词正在输入时保留系统文字菜单；谱面也支持 Shift+F10 打开快捷菜单。
- 全宽工作区：曲谱库、和弦实验室、编排编辑与阅读随可用窗口宽度铺开；原谱和演奏阅读的「适合宽度」也不再受固定纸张宽度限制。宽屏编排自动增加每行小节数，手机保持局部横向滑谱。
- 符号说明：鼠标悬停在编排谱面的数字 / ×、和弦图、延音线、延时横线、休止、符干 / 符尾 / 符杠、附点、三连音及扫弦箭头上，可查看名称和演奏含义。提示不拦截点谱输入，随修改更新，离开、滚动、切换视图或按 Esc 时收起；键盘聚焦已有音符和和弦也提供说明。此说明基于编排数据，上传的图片 / PDF 不做自动符号识别。

- 曲谱库：上传 JPG、PNG、WebP 或 PDF，整理曲名、作者、调性、变调夹和标签；收藏、搜索、排序与练习状态。曲谱卡片和阅读器均可删除曲谱，确认后同时移除原文件、笔记和编排；删除示范谱后刷新也不会重新出现。
- 阅读器：顶部页面缩略图、直接跳页、多页浏览、记住上次页码、调整页序、旋转、缩放、专注模式和自动滚动。图片与 PDF 按实际显示宽度和屏幕像素密度重新绘制；PDF 缩放与翻页复用已下载文档。
- 演奏阅读：从原谱进入独立全屏布局，按保存页序连续阅读图片和多页 PDF；选起始页（可跳过封面）、3/5 秒或无倒计时、可调速自动滚谱、空格暂停/继续、方向键及 PageUp/PageDown 移谱。拖动、切后台或调整窗口时暂停，谱尾停止；支持浏览器全屏和屏幕常亮（不支持时提示）。本设备记住速度、缩放与页内位置；原谱批注和识别继续在普通阅读器操作。共享 PDF 下载，稳定页面高度，仅渲染邻近页面，避免长谱堆积高清画布。
- 笔记：谱面圈选 / 点按批注、练习笔记；旋转时批注位置随页面变换。保存失败保留当前草稿。
- 和弦实验室：常用和弦与指型、交互指板、按弦位置反查和弦、变调夹换算、组成音与和弦试听、具体指型收藏。
- 换指练习：手动选择前后和弦，提示相同指位可保留的手指；将选定和弦加入临时进行，按设定速度循环试听。
- 节拍器：30–240 BPM，3/4、4/4、6/4；手机收起练习面板后仍继续运行。
- 备份与恢复：ZIP 包含原始曲谱、页序旋转、标签收藏、批注笔记、已保存编排、唱音与歌词、收藏指型。曲谱库中可恢复为副本，保留原库；多页 PDF 共用原文件，所有关联页会重新映射。支持旧 v1 ZIP，先验证格式、文件签名和引用再写入，数据库批量原子提交，失败清理本次新增文件。备份上限 200 MB，原文件上限 20 MB；导出前须保存草稿。浏览器中的滚谱和示范谱显示偏好不包含在 ZIP 中。
- 三份原创示范六线谱，不使用第三方曲谱内容。
- 编排与试听：原谱对照、段落和小节增删/复制/排序、具体和弦指型、十六分 / 三十二分、附点 / 复附点和三连音时值、休止、拍号、速度、段落播放遍数、整曲/选段循环、小节与事件高亮。提供和弦扫奏及八分分解音型，遵循当前曲谱的 Capo。
- 可视化编排：整张六线谱就是编辑区。点和弦可就地切换按法、拆分时值或清为空拍；切换八分、十六分、附点或三连音网格，点某弦的拍点直接输入 0–24 品；输入 X 或点「× 按和弦拨弦」跟随当前和弦的相应弦品位，方向键移动，Delete / Backspace 清除单音。手机使用工具栏的品位输入框和弦位选择器，谱面可横向滑动。谱面上可直接插入、复制、移动和删除小节，修改段落名与播放遍数；支持撤销、重做、同步试听及原谱页关联。每个单音可独立设置时值；选中前音可点「延音」或按 L 连接后面的同弦同品音符；没有下一同音时自动补续音，跨小节及跨多小节的空隙会补上延音段。选中后音可点「接前音」或按 Shift+L 与前音连接；工具栏和属性面板使用同一操作。不同品位及谱尾小节不足会明确提示原因，取消延音保留已写续音，合并后只拨弦一次。切换网格仍保留并显示已有音符。
- Guitar Pro 式写谱：固定时值面板与谱面光标，点击只定位，数字直接输入品位。时值与显示网格分开，空位可预选后续时值；改网格不清除光标。左右键按当前时值前进 / 后退，遇到中间已有起音先停在该拍位，上下键换弦；同拍可输入多弦。音符与和弦属性按需展开，选择音符不会滚到下方表单。
- 三连音输入：先选择基础时值，再打开「三连音」，网格会显示相应细分；输入一个品位后按右方向键继续输入下一个音。八分三连音的三个音合计一拍，完整组统一连梁并显示括号「3」，唱音简谱按相同节奏独立输入。三个音可以从半拍等位置开始，不会被普通拍界拆开，编辑和阅读均按组内时间等距排列。对已有单音切换三连音只改时值，保留原来的起音位置；已有普通八分音符需在三连音拍位重新填写。未填满的组按实际剩余时值补休止，不会显示长小数拍数。
- 片段复用：Shift + 左右键 / Shift + 点击扩展选区，手机可用「选择片段」设置起点再点击终点；复制、剪切与覆盖粘贴包含音符、和弦按法、奏法、休止和歌词。粘贴不挤动后续音符，跨小节的音拆分并连接延音，空间不足整次拒绝；每次操作可整体撤销。剪贴板保留在当前编辑器会话中。
- 编排快捷键：`+ / =` 缩短、`-` 延长、`.` 附点 / 复附点、`/` 三连音、`R` 当前时值内所有弦休止、`L` 延音 / 自动补续音、`Shift+L` 接到前音、Delete 清除当前单音、空格试听 / 停止；Ctrl / Cmd + C / X / V 复制 / 剪切 / 覆盖粘贴，Ctrl / Cmd + S 保存，Ctrl / Cmd + Z 撤销，Ctrl / Cmd + Shift + Z 重做。快捷键避开文本输入框；工具栏键盘图标可查看说明。休止会截断进入范围的持续音，保留歌词及范围外内容。
- 谱面与播放器共用拨弦数据，品位相对变调夹。缩短时值自动留下休止，延长只占用后续空拍；手动音符随拆分分配，复制互不影响。默认扫弦 / 分解变化保留手改音符；更换和弦保留手工音符与节奏，仅更新 × 的实际品位，明确数字不变。点击「恢复和弦音型」才重新生成该事件。可选同时拨弦、向下或向上扫弦；常见按法不合原谱时，可展开「核对原谱和弦按法」，逐弦填写品位。
- 弹唱谱排版：上方显示和弦名称及具体指型，中间为连续六线谱，下方依次为唱音简谱和歌词；相邻重复指型合并显示，密集换和弦自动分行，点击整张和弦图可编辑。吉他、唱音和歌词共用音乐时间轴，但各自存储起唱或拨弦位置。
- 歌词与唱音关联：默认两行，支持 1–8 行增删。歌词默认「跟随唱音」，对应同拍的唱音；移动唱音时带动各行关联歌词，移动关联歌词也会移动唱音。可以先填词再补唱音；选择「独立起唱」后歌词只按自己的时间移动，不必对齐吉他拨弦。删除唱音或改为休止时保留歌词并转为独立起唱。已有旧歌词无需迁移，同拍唱音按默认关联处理；音符或歌词冲突会整次拒绝覆盖。
- 歌词时间与排版：歌词工具栏分为「调整起唱」和「调整排版」。前者通过拖动、方向键、起唱拍位及提前 / 延后半拍改变音乐时间，支持跨小节；后者通过二维拖动、方向键或水平 / 垂直偏移只调整文字位置，不改变起唱与试听，支持重置。空白拍点只在当前编辑声部、当前歌词行显示，已有文字始终可以点击。首尾、连续及全角空格按输入原样保存，也可先填写空格；完全清空文本框才删除该处歌词。Tab / Shift+Tab 连续填写并跨小节，Enter 切换歌词行；中文输入法、长句换行、撤销重做、保存刷新、阅读和片段复制均保留。
- 一字多音：选中关联唱音的歌词，在「延唱至」选择后续唱音，歌词下方以细黑横线标出延唱范围，支持跨小节和换行接续。后续歌词出现时结束横线，避免穿过文字；解除延唱或末音被删除时保留原词。
- 唱音简谱：独立单声部人声旋律，点击唱音行任意位置，键入 1–7 写音级、0 写休止；调号以 1=C 等形式显示，支持上下两个八度、升降号、附点 / 复附点、三连音，以及全音符至三十二分时值。音上 / 下点表示八度，音下单 / 双 / 三线表示八分 / 十六分 / 三十二分，并按节拍连接；长音显示增时横线，同音延音在数字上方画黑色弧线，跨小节自动拆分、连续或换行接续。上下键改八度，左右键按时值移动光标，L 连接续音，+ / - / . / / 调整时值。工具栏可移动整条唱音延音链；与其他唱音冲突时整次拒绝。歌词可关联唱音一起移动，也可选择独立起唱；与文字排版偏移分别保存。
- 分声部试听：编辑与编排阅读可选择吉他、唱音旋律或合奏。吉他继续使用拨弦音色与曲谱 Capo，人声旋律按唱音调号使用合成持续音色，休止和延音遵循谱面节奏；当前不将歌词合成为真人歌唱。保存、撤销、备份及选区复用包含歌词与唱音，跨调粘贴保留实际音高。
- 节奏谱面：符干直接从六线谱上的音符向下延伸，一条符杠表示八分音符，两条表示十六分，三条表示三十二分；同拍同时值多弦用竖线连接并共用符干，同拍不同时值分层显示。普通全音符显示三条延时横线，二分音符显示一条，横线只表示保持声音，不增加拨弦；附点和三连音时值单独保留。保留附点 / 复附点、休止及三连音括号；完整三连音显示「3」，不完整组显示「3:2」，6/8 按三枚八分音符分组。空拍按 4/4、3/4 的四分拍界或 6/8 的两个复合拍拆分；只在已出现的三连音组内补三连休止，整小节空白以居中全休止表示，实际时长仍遵循拍号。谱面直接显示休止符，不再重复标注“休”；6/8 的谱面、光标状态及读屏拍位统一按 1–6 计数（速度仍以四分音符计）。默认扫弦音型也显示与试听方向一致的箭头。延音线为音符上方的黑色浅弧，采用两端细、中间稍厚的印刷轮廓；唱音弧线根据八度点自动调整高度，六线谱弧高限制在弦线间，跨小节统一轮廓，换行用行尾悬挂 / 行首接入的接续弧；符杠分组的音仍分别拨弦，延音线连接的同音只拨一次。
- 编排阅读：原谱阅读、编排阅读、编排编辑分为三个独立视图。编排阅读将所有段落和小节连成完整谱面，支持缩放、整曲试听、循环与自动滚动；编辑页可一键进入阅读，已保存编排在重新打开曲谱后仍可阅读。未保存预览会单独标明。
- 编排保存与草稿：保存在曲谱 JSON 中，完整备份包含编排；还可单独导出编排 JSON。未保存修改在当前页面的琴房中暂存，切换曲谱或和弦实验室可继续编辑；离开或刷新浏览器会提醒保存。旧保存响应不会清除后来的修改。

- 六线谱片段识别：在原谱阅读中点击「框选识别」，或从编排工具栏进入，拖出一行完整小节。浏览器本地检测弦线、小节线、品位和部分常见和弦标记；图片读取原文件，PDF 独立高清渲染选区，不包含批注。首次识别需加载随站点提供的 OCR 资源，曲谱图像不发送给外部识别服务。
- 识别校正：逐小节对照高清原图片段与草稿，修改品位、弦位、拍点及和弦，移除误识别或补入漏音。× 按当前拍点的和弦指型解析，数字保留指定品位；支持自定按法及小节内多次换和弦，追加时按换和弦拍点分成事件。识别出的多个和弦会保留为待核对的换和弦位置。确认每小节的音符和节奏后，追加为一个可编辑段落；保留现有编排并可一次撤销。关闭校对或在琴房内切换页面会保留当前识别草稿，重新框选失败不会丢弃旧草稿；刷新页面前需完成加入和保存。

## 阶段边界

当前试听来自手动编排或识别后校正的和弦与音符，以及手动输入的唱音旋律，使用浏览器合成拨弦与持续音色。可视化编辑作用于编排中的六线谱、唱音及歌词，不修改上传的原文件，也不提供歌词歌唱合成。

本地识别目前适合清晰、水平、印刷的六线谱，一次一行，建议 1–4 个完整小节，最多 8 小节。纯歌词和弦谱、手写谱、斜拍、复杂装饰符号及自动整页识别尚未支持。当前采用中文弹唱六线谱的读法：「×」表示按相应和弦拨对应弦，数字指定该弦的实际品位（可以覆盖和弦按法）。未设置和弦或对应弦不可弹时，必须补全按法才能确认 / 保存，不会猜成空弦；尚不能可靠处理整页混合简谱、歌词、和弦图和复杂节奏的弹唱谱，也不支持闷音试听。不同字体仍可能误读或漏读，必须逐小节核对，不能将识别置信度当作准确性保证。拍点按音符列均匀排布作为草稿，尚未自动读懂节奏；弦位、品位、和弦与拍点均可人工修正。当前编排已有段落时，新识别片段的拍号必须一致。后续再扩展更完整的节奏识别、弹唱谱识别、演奏示范与同步落指引导。

编排 v2 以四分音符为 24 tick：4/4 每小节 96 tick，3/4 与 6/8 每小节 72 tick；速度仍以四分音符每分钟计。支持十六分 / 三十二分、附点二分 / 四分 / 八分 / 十六分、复附点二分 / 四分 / 八分，以及四分 / 八分 / 十六分 / 三十二分三连音。事件占满小节，音符起音和独立时值分别保存；延音只连接时间相邻的同弦同品音符。输入或调整单音时值时可跨小节，自动在小节线处分成延音相连的续音；谱面按连续谱行排列，同一行画完整黑色延音弧线，换行则两端接续。跨小节仅延续同弦同品音，试听合并为一次拨弦。缩短、删除及改品位会同步处理该音后续的延音链；后续同弦独立音不会被自动覆盖，小节不够时提示先添加。改变网格不移动已有音符；缩短事件不能丢弃后面的音符，插入后音会截短同弦前音，删改音符会清理失效的延音。最多 16 段、128 小节，每段 1–8 遍，每事件最多 144 个手动音符。

旧 v1 编排在读取时按 12 倍换算时值和起音位置，保持原速度、分解密度及原有试听，写入版本校验仍使用原始记录，无需数据库迁移。旧版本备份提交到 API 也会升级为 v2。识别草稿仍按八分网格排布，加入编排时换算为新时间单位；复杂节奏需要在编排页人工校正，尚未增加自动节奏识别。选段保留段落遍数；延音不会误连到反复或循环跳转后的音，从续音所在小节单独开始试听时会正常拨响。

编排侧当前支持单吉他轨、独立单声部唱音与多行歌词的谱面输入、编辑及试听；参考 Guitar Pro 的交互流程，尚未实现其完整多轨工程和原生 GP 文件导入。识别功能保留已有能力，暂不继续扩展。

## 记谱参考

- [Guitar Pro：歌词](https://www.guitar-pro.com/docs/gp8/score/lyrics)与[W3C MusicXML：歌词](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/lyric/)：歌词通常对应人声旋律，支持多行及[一字多音延唱](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/extend/)。本项目以唱音关联为默认，另提供独立起唱模式；音乐时间和文字排版偏移分开保存。

- [吉他老师高峰：吉他谱上的常见标记与符号](https://www.zhihu.com/tardis/zm/art/214066781)：本轮参考音符时值、休止、扫弦和同时拨弦图例修正规则。文章中的击弦 / 勾弦、滑音、推弦、泛音、震音等技巧尚未实现，当前延音线仅表示同音延续。
- [MuseScore：整小节休止](https://musescore.org/en/handbook/4/measure-rests-and-multimeasure-rests)：整小节空白用居中的全休止形状，实际时长依据拍号。

- [吉他社：吉他谱六线谱入门](https://www.jitashe.org/school/tablature/)：弹唱谱的 × 根据上方和弦按弦，数字明确指定品位。当前产品使用这一约定；Guitar Pro 中 × 作为 dead note 的约定不同，目前没有导入 Guitar Pro 文件或闷音试听。
- [Guitar Pro：音符输入](https://www.guitar-pro.com/docs/gp8/score/note/note-input)、[快捷键](https://www.guitar-pro.com/docs/gp8/appendix/shortcuts)与[复制粘贴](https://www.guitar-pro.com/docs/gp8/score/assistant/copy-paste)：谱面光标、时值面板和片段复用的交互参考。
- [Guitar Pro：连音](https://www.guitar-pro.com/docs/gp8/score/note/tuplet)与[时值符号](https://www.guitar-pro.com/docs/gp8/score/note/symbols/note)：三连音按正常两枚音符的时间演奏三枚，附点增加原时值的一半，复附点再增加四分之一。
- [Guitar Pro：六线谱节奏排版](https://www.guitar-pro.com/docs/gp8/preferences-stylesheet/stylesheet/notation)与[符干及符杠](https://www.guitar-pro.com/docs/gp8/score/note/symbols/notation)：将节奏符干连接到六线谱音符，并在谱线下方组织符杠。
- [MuseScore：符杠](https://handbook.musescore.org/notation/rhythm-meter-and-measures/beams)：用符杠组织节拍内的短时值音符。当前实现固定拍号的常见分组，尚不支持用户自定符杠或任意连音比。

- [MuseScore：连音线与延音线](https://handbook.musescore.org/notation/expressive-markings/slurs-and-ties)：延音的端点位置、端细中粗的曲线轮廓及换行接续排版。

## Windows 本地体验版

首版支持 Windows 10/11 x64，使用 Edge 或 Chrome。发行包内带 Node.js、预编译网页、本地数据库与文件存储运行时，以及 PDF / OCR 静态资源；使用时不需要安装开发工具、登录或联网。未发布线上版本。

解压完整的 `GuitarRoom-0.1.5-windows-x64.zip`，双击「启动弦间.cmd」。首次自动初始化，浏览器随后打开 http://127.0.0.1:5180/ 。保留启动窗口；使用结束先保存编排，再双击「关闭弦间.cmd」或在启动窗口按 Ctrl+C。重复启动复用已有琴房；端口被其他程序占用时提示错误，不终止其他软件。关闭启动窗口或进程中断时，守护会在确认父进程退出后清理本应用的子进程；数据库命令正常断开通信不会触发强制清理。

曲谱原文件、编排、歌词、唱音、批注、笔记及收藏指型存放在当前 Windows 账户的 `%LOCALAPPDATA%\GuitarRoom`，与程序文件夹分开。双击「打开数据目录.cmd」查看。升级前停止旧版本，再解压新包使用同一数据目录即可；初始迁移可重复执行，已有数据不会覆盖。日志位于其中的 `logs`。卸载程序不会删除数据，删除数据前请先导出完整备份。滚谱速度、阅读位置与示范谱显示偏好保存在所用浏览器。

旧开发库与体验版是独立目录，启动器不会自动搬走或打包现有私人曲谱。可先在旧网页导出 ZIP，再在体验版曲谱库点「恢复备份」。分享给朋友的发行包只有程序和原创示范谱。

### 构建发行包

在 Windows x64 开发电脑安装依赖后执行：

```sh
npm run package:windows
```

脚本先检查 TypeScript 并构建，再仅复制运行所需依赖及本机 Node 可执行文件。内置运行时必须附对应版本的官方许可证；当前包含 Node.js 24.18.0 许可证，可用 `--node` / `--node-license` 指定其他兼容版本。许可来源是 [Node.js 官方仓库](https://github.com/nodejs/node/blob/v24.18.0/LICENSE)。朋友使用时不会下载或安装依赖。 Windows CRT DLL 从构建电脑上 Visual Studio 的正式 `VC/Redist/MSVC/<版本>/x64/Microsoft.VC*.CRT` 目录复制到程序旁；不依赖朋友已经安装 VC++，也不安装或修改系统库。其他构建环境可用 `--vc-runtime-dir` 指定对应正式可再分发目录，必须具备相应分发许可。DLL 版本与校验值记在 manifest，随本程序版本更新。部署方式参见 [Microsoft 本地部署说明](https://learn.microsoft.com/en-us/cpp/windows/deployment-in-visual-cpp)。

输出目录 `outputs/GuitarRoom-<版本>-windows-x64`、ZIP、SHA256 校验文件均已忽略。包内 `release-manifest.json` 记录版本、源提交/未提交状态、运行时及 Node 校验值；第三方许可放在 `runtime/LICENSE.txt`、`licenses` 和 `THIRD-PARTY-NOTICES.json`。构建输入排除真实数据、开发状态、环境变量文件和凭证。需要重新打包时先关闭使用该程序目录的本地服务，再运行 `npm run package:windows -- --replace`。

直接测试预编译本地版：

```sh
npm run build
npm start
npm run local:stop
npm run local:data
```

测试时可指定隔离数据目录与端口：`node scripts/local-app.mjs start --no-open --data-dir ".qa/local-test-data" --port 5187`。所有启动、停止、状态命令须指向相同数据目录，也可设置 `GUITAR_ROOM_DATA_DIR`。常规开发仍用 `npm run dev`。

## 本地运行

需要 Node.js 22.13 或更高版本。此项目使用 React、TypeScript、vinext / Vite、Cloudflare D1 与 R2、PDF.js 和 Web Audio。

```sh
npm ci
npm run dev
```

默认开发地址为 http://localhost:5173/ 。直接打开本机开发服务即可导入曲谱、保存笔记与编排、收藏和弦，不依赖登录 Cookie。沿用开发目录的 `.wrangler/state`，已有曲谱无需重新导入。开发数据不会进入发行包。免登录访问必须同时满足本机请求主机与开发模式，或本地启动器设置的显式 `GUITAR_ROOM_LOCAL_APP=1` worker 绑定；未启用的生产服务、其他主机及跨来源写入拒绝访问。

新检出的目录还需要初始化本地数据库（只执行一次；现有工作区已经执行）：

```sh
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_left_gwen_stacy.sql
```

`.openai/hosting.json` 声明 DB 和 BUCKET 绑定。数据库保存曲谱信息、笔记和指型，R2 保存原始文件；API 校验本机使用范围、请求来源、文件签名和写入版本。多标签页使用旧版本保存时返回冲突，防止静默覆盖。曲谱删除先写入只保留标识的删除记录并关闭文件访问，再清理存储；清理中断会在下次读取曲谱库时重试，无需数据库迁移。迟到的列表响应不会恢复已删除项或覆盖刚完成的保存。

单次导入可选最多 20 张图片，或 1 份最多 200 页的 PDF。每个文件不超过 20 MB，单次总量不超过 40 MB。第一期使用标准调弦 E A D G B E。
